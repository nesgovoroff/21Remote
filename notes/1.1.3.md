21 Remote 1.1.3 for macOS 10.10–10.15 (Intel): remote control for D21m frames. For macOS 11 and newer use the regular release.

- The rack and its cards, gain, 48 V, filters, names, colours, comments, sessions with undo and redo.
- Connection through a local serial port or a serial device server on the network (TCP Server or TCP Client mode).
- MIDI: a virtual port with a fixed controller map for DAWs, and MIDI Learn for hardware controllers.
- DAW plug-ins 21 Channel and 21 Overview: JS (REAPER) on all versions, Audio Unit and VST3 on macOS 10.13 and later; the plug-ins start the app by themselves.
- Window menu: Scale 50–125 %, Zoom In, Zoom Out, Actual Size.
- Updates from Settings > Updates.

**Install:** download `21-Remote-1.1.3-macOS10.pkg` and open it. The installer is not signed with a developer certificate: if macOS stops it, open System Preferences → Security & Privacy and click "Open Anyway", or right-click the package and choose Open. On OS X 10.10 and 10.11 install the last Safari update for your system first.
