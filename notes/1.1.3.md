21 Remote 1.1.3 for macOS 11 and newer (Apple Silicon and Intel): remote control for D21m frames.

- The rack and its cards, gain, 48 V, filters, names, colours, comments, sessions with undo and redo.
- Connection through a local serial port or a serial device server on the network (TCP Server or TCP Client mode).
- MIDI: a virtual port with a fixed controller map for DAWs, and MIDI Learn for hardware controllers.
- DAW plug-ins 21 Channel and 21 Overview as Audio Unit, VST3 and JS (REAPER); the plug-ins start the app by themselves.
- Window menu: Scale 50–125 %, Zoom In, Zoom Out, Actual Size.
- Updates from Settings > Updates.

**Install:** download `21-Remote-1.1.3.pkg` and open it. The installer is not signed with a developer certificate: if macOS stops it, open System Settings → Privacy & Security and click "Open Anyway".
