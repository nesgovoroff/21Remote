Communication

USB serial adapters appear as cu.usbserial-…, cu.usbmodem… or cu.wchusbserial…. The port runs at 115200 baud, 8N1, no handshake.

In the configuration of the serial device server (RS-232 to Ethernet) set the serial port the D21m is wired to to TCP Server mode. Serial settings: 115200, 8 data bits, no parity, 1 stop bit, flow control none. Enter the data port of that serial port; many device servers use 4001 for serial port 1 and 4002 for port 2. The app reconnects by itself if the link drops.

In the configuration of the serial device server set the serial port to TCP Client mode, with destination IP this Mac’s address and the TCP port above. Serial settings: 115200 8N1, flow control none; connection control “Startup/None”. macOS asks once whether to allow incoming connections. Choose Allow.

The built-in simulator behaves like a D21m frame with a mix of cards, so you can try the app without hardware.

Gain values are exact steps in dB, so automation written in the DAW reproduces the same gain. Changes made on the rack, in this app or from a controller are sent to the DAW as the same CC messages, so they can be recorded as automation.
