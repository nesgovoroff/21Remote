# 21 Remote

Программа для удалённого управления стойкой D21m с Mac: карты и каналы стойки, усиление, 48 V, фильтры, сессии,
управление по MIDI, плагины для DAW (AU, VST3, JS).

**Ветка `old_macos`: сборка для macOS 10.10–10.15 (Intel).** Для macOS 11 и новее — ветка `main`. Свободная
программа под лицензией **GNU AGPL v3** (см. [LICENSE](LICENSE) и [NOTICE](NOTICE)).

### Чем сборка для macOS 10.10–10.15 отличается

* Релизы этой ветки называются `v<версия>-macos10`, установщик — `21-Remote-<версия>-macOS10.pkg`. Программа
  обновляется только из них, а сборка для новых macOS их не видит.
* Только Intel. Движок собран на **Go 1.12** — последней версии Go, которая работает на macOS 10.10; поэтому код
  движка не использует новые возможности Go (вместо них пакет `internal/compat`).
* Интерфейс при сборке приспосабливается к WebKit старых macOS (`macos/legacyweb.py`, `web/legacy/`): скрипт
  переводится в ES2016, добавляются замены `<dialog>`, событий указателя и `gap` во flex-разметке. Для
  OS X 10.10 и 10.11 установите последнее обновление Safari для своей системы.
* Плагины **AU и VST3 — для macOS 10.13 и новее** (старее нынешний Xcode не собирает); на 10.10–10.12 установщик
  их не предлагает. JS-плагины для REAPER работают на всех версиях.
* Масштаб окна до macOS 11 делается средствами CSS.

> 21 Remote — независимый проект. Он не связан с производителем стойки D21m, не одобрен и не поддерживается им.
> D21m — товарный знак своего владельца; названия форматов и платформ (VST, Audio Units, macOS, REAPER)
> упоминаются только для описания совместимости. Программа распространяется **без каких-либо гарантий**. Она
> управляет фантомным питанием и другими функциями реального оборудования: проверяйте настройки перед работой.

## Установка

1. Скачайте `21-Remote-<версия>.pkg` из раздела **Releases**.
2. Откройте файл. Установщик не подписан сертификатом разработчика, поэтому macOS при первом открытии его
   остановит. Откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**
   рядом с сообщением об установщике (в macOS 14 и старше можно также щёлкнуть файл правой кнопкой → «Открыть»).
3. Установщик спросит пароль администратора и поставит:
   * приложение **21 Remote** в «Программы»;
   * плагины **21 Channel** и **21 Overview** в форматах Audio Unit и VST3 (для всех пользователей,
     `/Library/Audio/Plug-Ins`);
   * JS-плагины **21 Channel** и **21 Overview** в папку JS-эффектов пользователя.

   Кнопка «Настроить» на шаге «Тип установки» позволяет выбрать части. Перед установкой закройте DAW, после —
   запустите заново.

Если плагины раньше копировались вручную в `~/Library/Audio/Plug-Ins`, установщик удалит эти копии, чтобы DAW не
показывала их дважды.

## Первый запуск

Пока подключение не выбрано, программа показывает пустую стойку и две кнопки:

* **DEMO** — встроенный симулятор стойки, чтобы попробовать программу без оборудования;
* **CONNECT** — переход в **Settings** для выбора подключения.

Дальше программа при запуске сама подключается к последней выбранной стойке. Демо-режим сам не включается.

## Окно, Dock и значок в строке меню

Программа работает как обычное приложение: она есть в Dock и в переключателе ⌘Tab и закрывается через ⌘Q.
Закрытие окна только сворачивает его: программа продолжает работать, а в строке меню остаётся её значок.

* Щелчок по значку в Dock, переключение на программу (⌘Tab) или щелчок левой кнопкой по значку в строке меню
  снова показывает окно.
* Щелчок правой кнопкой по значку в строке меню открывает меню **Open**, **Settings**, **Quit**.
* Если программу запускает плагин из DAW (или скрипт 21 Remote Bridge), она открывается свёрнутой: окна нет, есть значок
  в Dock и в строке меню.
  Запущенная отдельно, программа открывается как обычно, с окном.

## Подключение

### USB-адаптер RS-232

**Settings → Connection → USB or serial port on this Mac**. Адаптеры видны как `cu.usbserial-…`, `cu.usbmodem…`,
`cu.wchusbserial…`. Нужен драйвер адаптера, если macOS его не поддерживает сама. Порт работает на **115200 бод,
8N1, без управления потоком, DTR и RTS выключены** и открывается эксклюзивно. Если адаптер выдернули, программа
покажет «offline»; после повторного подключения нажмите **Apply**.

### По сети через преобразователь RS-232 ↔ Ethernet

Последовательный порт преобразователя, к которому подключена стойка: **115200, 8 бит, без чётности, 1 стоп-бит,
без управления потоком**. Режим работы:

| Режим порта преобразователя | Что выбрать в программе | Что указать |
|---|---|---|
| **TCP Server** | «Network: connect to device server» | IP-адрес преобразователя и порт данных (часто 4001 для порта 1, 4002 для порта 2) |
| **TCP Client** | «Network: device server connects here» | Порт, который слушает программа (по умолчанию 4001). В преобразователе: адрес Mac (показан в настройках) и тот же порт |

* Программа сама переподключается после обрыва. Время ожидания ответа по сети — 500 мс.
* В настройках преобразователя полезно ограничить число подключений одним и включить проверку соединения
  (keep-alive) на 1–2 минуты, а упаковку данных (packing, delimiter, force transmit) выключить.
* macOS спросит разрешение на доступ к **локальной сети**. Его можно запросить заранее в **Settings → Permissions**.
* В режиме TCP Client macOS может спросить, разрешить ли входящие подключения. Нужно разрешить.
* Имитатор преобразователя со стойкой для проверки без оборудования: `go run ./tools/fakeserver -listen :4001`
  или `go run ./tools/fakeserver -connect <IP Mac>:4001`.

## Окно программы

* **Rack** — стойка с картами в слотах (блок питания справа), тип модуля и состояние. Щелчок по карте показывает
  или скрывает её в Channels. В списке карт указано число аудиоканалов (входы / выходы); карта показывается в
  том слоте, который опрашивался.
* **Channels** — полосы каналов всех карт:
  * Mic (4 канала): усиление −11…+75 дБ, 48 V, HPF, Insert, Soft clip, стерео-линк;
  * DL5 Mic (8 каналов): усиление −13…+62 дБ, 48 V, HPF, DC servo, CM servo, стерео-линк;
  * AES/EBU: индикаторы Lock, SFC, частота и разрядность выходов; ADAT: индикаторы Lock;
  * GPIO: 16 GPI и 16 GPO; прочие карты: сведения и hex-редактор командного поля;
  * имя канала (двойной щелчок по цветной полосе), цвет (контекстное меню → палитра 7 × 4), порядок
    (перетаскивание или Move left/right), скрытие карты;
  * **Gang**: щелчок — только этот канал, ⌘-щелчок — добавить или убрать, ⇧-щелчок — диапазон;
  * фейдер: мышь, колесо, ↑/↓ — шаг, PgUp/PgDn — 5 шагов, Home/End — пределы, ←/→ — соседний канал;
  * **комментарий** внизу канала: щелчок — писать, Enter — сохранить, ⇧Enter — новая строка, Esc — отмена.
* **Settings** — подключение, интервал опроса, шаг фейдера, MIDI, разрешения macOS, обновления, журнал обмена.
* **Сессии** — кнопки **New Session** (голубая), **Open Session** (жёлтая), **Save Session** (бордовая) и меню
  File: New Session (⌘N), Open Session… (⌘O), Open Recent, Save Session… (⌘S). Сессия — это файл с настройками
  стойки, именами, цветами, комментариями и порядком каналов. **New Session** ставит все микрофонные каналы на минимальное
  усиление с выключенными 48 V, HPF, Insert и Soft clip (DC и CM servo каналов DL5 не трогает) и возвращает имена,
  комментарии, цвета, порядок, видимость карт, стерео-линки и имя стойки к исходным. Перед новой сессией и перед
  открытием другой программа спрашивает: сохранить текущую, продолжить без сохранения или отменить. Если при
  открытии сессии состав карт не совпадает, программа покажет различия и предложит восстановить совпадающие карты.

Имена, цвета, комментарии, порядок и видимость каналов программа запоминает сама и восстанавливает при следующем
подключении к стойке (для демо-режима отдельно). Усиление и кнопки всегда берутся из стойки.

### Панель слева

* **Racks** — стойка: имя, модуль, состояние, подключение и миниатюра. Щелчок открывает вид Rack, и стойка мигает.
* **48 V OFF** — выключить фантомное питание на всех картах и каналах (с подтверждением). Программа запоминает,
  где оно было включено, и кнопка становится **48 V RESTORE**: повторное нажатие (тоже с подтверждением) включает
  48 V только на этих каналах. Список сохраняется и после перезапуска.
* **Take ch. names from DAW** — записать в имена каналов имена треков DAW, на которых стоит плагин 21 Channel
  (AU/VST3) с выбранным каналом. Имя трека плагину передаёт DAW; плагин показывает полученное имя.
* **Reset ch. names** — убрать все имена (с подтверждением). **Reset Channel Order** — вернуть порядок слотов.
* **Undo / Redo**.

### Отмена

**⌘Z** отменяет последнее действие, **⇧⌘Z** повторяет: кнопки и усиление (движение фейдера — один шаг),
стерео-линк, AES/GPO, имена, цвета, комментарии, порядок и скрытие каналов, имя стойки, открытие и новую сессию,
48 V OFF/RESTORE, сброс имён и порядка. Подключение и настройки не отменяются. Изменения из DAW (автоматизация,
MIDI) в список не попадают: у DAW своя отмена. Во время ввода текста ⌘Z отменяет набранный текст.

## MIDI

MIDI работает в приложении (в браузере недоступен) и настраивается в **Settings → MIDI**.

**Порт «21 Remote».** Приложение публикует виртуальный MIDI-порт «21 Remote» (вход и выход) с фиксированной
картой: **MIDI-канал = номер слота (1–12)**, номер CC = параметр.

| Карта | CC | Параметр | Значения |
|---|---|---|---|
| Mic | 1–4 | Усиление канала 1–4 | 0–86 = −11…+75 дБ |
| DL5 Mic | 1–8 | Усиление канала 1–8 | 0–75 = −13…+62 дБ |
| Mic, DL5 | 21–28 | 48 V | 0 выкл, 127 вкл (≥64 = вкл) |
| Mic, DL5 | 31–38 | HPF | 0 / 127 |
| Mic / DL5 | 41–48 | Insert / DC servo | 0 / 127 |
| Mic / DL5 | 51–58 | Soft clip / CM servo | 0 / 127 |
| GPIO | 1–16 | GPO 1–16 | 0 / 127 |
| GPIO | 21–36 | GPI 1–16 (только передача) | 0 / 127 |
| AES/EBU | 1–8, 9–10 | SFC входов 1–8, выходов 1–4 / 5–8 | 0 / 127 |
| AES/EBU | 11–12 | FS out 1–4 / 5–8 | 0 = 44.1, 1 = 48, 2 = 96, 3 = ext |
| AES/EBU | 13–20 | Разрядность выхода 1–8 | 0 = 16, 1 = 18, 2 = 20, 3 = 24 бит |
| любая | 127 | Запрос: прислать все значения слота | любое |

Порт работает в обе стороны: изменения со стойки, из программы и с контроллеров уходят теми же CC (их можно
записать в автоматизацию), а при воспроизведении автоматизация управляет стойкой. **Send all values** отправляет
все текущие значения.

**MIDI Learn.** Кнопка **MIDI Learn** в верхней панели: щёлкните фейдер, кнопку, GPO или переключатель AES и
пошевелите ручку контроллера. Работают CC, ноты и Pitch Bend (14 бит). Режимы: Absolute / Relative для фейдеров и
энкодеров, Toggle / Follow для кнопок. С включённым «Send values back to controllers» моторизованные фейдеры и
светодиоды показывают реальное состояние стойки. Привязки хранятся в
`~/Library/Application Support/21 Remote/midi.json`.

## Плагины для DAW

### AU и VST3

Плагины работают через приложение 21 Remote (локальное соединение, порт 47210). Если приложение не запущено,
плагин запускает его в фоне — только значок в строке меню.

**21 Channel** — ставится на трек (звук проходит без изменений):
* выбор канала стойки (Mic и DL5), имя и цвет канала берутся из программы;
* автоматизируются **Gain**, **HPF**, **Insert / DC servo**, **Soft clip / CM servo**; **48 V** — кнопка, которая
  намеренно не автоматизируется;
* поле **Comment** — комментарий канала, общий с программой (хранится в программе);
* передаёт программе имя трека для **Take ch. names from DAW**;
* по умолчанию показывает состояние стойки; галочка «Send these settings to the rack when the project opens»
  восстанавливает настройки проекта в стойку (кроме 48 V).

**21 Overview** — полный интерфейс программы внутри DAW и 16 назначаемых слотов автоматизации.

### JS-плагины

**21 Channel** и **21 Overview** в формате JS выглядят и работают так же, как AU/VST3:

* **21 Channel** — выбор канала из списка (с именами каналов), фейдер усиления с зонами MIC/LINE, кнопки
  48 V, HPF, Insert / DC servo, Soft clip / CM servo, комментарий канала (правится прямо в плагине, хранится в
  программе), цветная полоса с именем и галочка «Send these settings to the rack when the project opens»;
* **21 Overview** — все микрофонные каналы стойки полосами, как в программе (усиление, 48 V, HPF, опции, имена,
  цвета, комментарии), и 16 слотов автоматизации, которые назначаются любому элементу стойки.

JS-плагин не может сам связаться с другой программой, поэтому вместе с ними ставится скрипт **21 Remote Bridge**. Он
запускается вместе с REAPER (установщик добавляет его в `Scripts/__startup.lua`) и связывает JS-плагины с
программой напрямую, без MIDI и без настройки треков. Если программа не запущена, скрипт запускает её свёрнутой.

* После установки **один раз перезапустите REAPER**, чтобы скрипт запустился.
* Если плагин пишет «The 21 Remote Bridge script is not running», запустите вручную
  `Scripts/21 Remote/21 Remote Bridge.lua` (Actions → Show action list → New action → Load ReaScript) или перезапустите REAPER.
* Имена треков с JS-плагином 21 Channel тоже доходят до программы: **Take ch. names from DAW** работает.

Gain, HPF и опции автоматизируются; 48 V переключается кнопкой и не автоматизируется. При открытии проекта плагин
показывает состояние стойки и ничего в ней не меняет (если не включена галочка восстановления настроек).
Файлы: эффекты в `~/Library/Application Support/REAPER/Effects/21 Remote`, скрипт в
`~/Library/Application Support/REAPER/Scripts/21 Remote`, копия всего в `/Library/Application Support/21 Remote/JSFX`.

## Обновления

Программа проверяет GitHub на новую версию (через 20 секунд после запуска и затем каждые 6 часов) и сама ничего не
устанавливает. Когда выходит новая версия, в верхней панели появляется зелёная кнопка **Update**, которая ведёт в
**Settings → Updates**:

* **Check for updates** — проверить сейчас, со списком изменений;
* **Update to …** — скачать установщик, ввести пароль администратора, установить программу и плагины и
  перезапустить программу. DAW после обновления нужно перезапустить;
* **Check automatically** — фоновая проверка.

Обновления берутся из публичного репозитория, токен не нужен: поле **Settings → Updates → GitHub access** оставьте
пустым. Если репозиторий сделать приватным, рядом с кнопкой обновления появится **Updates: token needed**: тогда
создайте на github.com → Settings → Developer settings → Personal access tokens → *Fine-grained tokens* токен с
доступом только к этому репозиторию и правом *Contents: Read-only* и вставьте его в это поле (хранится в связке
ключей; чтобы удалить, сохраните пустое поле).

## Разрешения macOS

**Settings → Permissions**:
* **Local network** — запросить доступ к локальной сети (нужен для преобразователя RS-232 ↔ Ethernet) и открыть
  соответствующий раздел системных настроек;
* **Files and folders** — запросить доступ к «Рабочему столу», «Документам» и «Загрузкам» для сессий;
* **Full disk access** — открыть раздел настроек (для сессий на других дисках и сетевых томах);
* права администратора спрашиваются при установке обновления.

Настройки: `~/Library/Application Support/21 Remote/settings.xml`. Журнал: `~/Library/Logs/21 Remote.log`.

## Как это устроено

* `cmd/remote21-core` — движок на Go без cgo: опрос стойки, очередь команд, MIDI-логика, API для плагинов, локальный
  веб-сервер интерфейса (127.0.0.1, вход по одноразовому токену).
* `macos/shell.c`, `macos/midi.c` — оболочка окна (WKWebView, меню, значок в строке меню) и мост CoreMIDI на C через
  Objective-C runtime.
* `web/` — интерфейс (HTML/CSS/JS), встраивается в движок.
* `plugins/` — AU/VST3-плагины (C++, JUCE) и JS-плагины.
* `internal/proto` — протокол стойки: кадр `[0x80|адрес][данные][контрольная сумма]`, 115200 8N1.

## Сборка

* Нужен **Go 1.12** (`GO=/путь/к/go1.12/bin/go`); код должен собираться и им, и новым Go.
* Тесты: `go test ./...`
* Приложение: `GO=… ./macos/build.sh` (на Linux или Intel-Mac; нужны clang, ld64.lld, python3 с Pillow и esbuild).
* Плагины AU/VST3: `cmake -S plugins -B plugins/build && cmake --build plugins/build` (macOS).
* Установщик: `./macos/pkg.sh` после сборки приложения и плагинов (macOS).

Версия задаётся в файле `VERSION`, описание релиза — в `notes/<версия>.md`. GitHub Actions собирает всё на каждый
коммит, а релиз публикует, когда в `VERSION` записана версия, для которой релиза ещё нет. Workflow **maintenance**
(запуск вручную в Actions) удаляет старые релизы и обновляет описание релиза.
